# n8n Code node runs multiple times: branches, items and HTTP calls

A focused, reproducible explanation of one failure mode: several branches reach
the same Code node, so "Run Once for All Items" runs once for each arrival.

[Analyze your workflow locally in CompSetly](https://news.compsetly.com/tools/n8n-fan-in/?src=shared).
No account is needed. Workflow JSON stays in the browser. The analyzer does not
execute Code nodes. A proposed Append change downloads as a separate inactive clone.

## Measured behavior

Native n8n **2.45.4**, execution order **v1**, five synthetic items:

| Workflow | HTTP node runs | Actual loopback HTTP requests |
|---|---:|---:|
| Two branches → batch Code → HTTP | 2 | 2 |
| Append → batch Code → HTTP | 1 | 1 |
| Append → HTTP, one item per request | 1 | 5 |
| Clone generated by our analyzer → batch Code → HTTP | 1 | 1 |

The experiment counts actual requests to a finite local counter. It makes no
external provider calls and does not establish cost savings, market demand or traffic.

## Reproduce

Install n8n 2.45.4 separately with its supported Node.js version. Use Python 3.
Run the harness with an empty, isolated n8n user folder:

```sh
python scripts/reproduce.py --n8n-bin /absolute/runtime/node_modules/n8n/bin/n8n --user-folder /absolute/isolated-user-folder --output /absolute/results --model /absolute/repository/model.mjs
```

Repeat with `--patch-only` to execute the analyzer-generated clone. The harness
imports only its own synthetic fixtures and stops its loopback counter after the run.
Keep generated private logs private. See [README.txt](README.txt) for details.

```sh
node --test tests/fanin.test.mjs
```

## Scope

The graph analyzer separates triggers, stops automatic rewriting for loops,
conditional or unknown execution semantics, and distinguishes potential branch
arrivals from actual API requests. Empty branches, retries, custom code, item
pairing and other n8n versions need their own tests. A generated clone needs
review before execution or publication.

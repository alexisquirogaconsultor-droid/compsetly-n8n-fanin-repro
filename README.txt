CompSetly n8n branch-convergence evidence kit

Own code and synthetic fixtures. No third-party workflow or execution log included.
The browser tool does not execute imported Code nodes. This reproduction harness
does execute only its own generated synthetic workflows in an isolated n8n install.
It starts a finite loopback HTTP counter, runs three fixtures, and stops the counter.
Do not import or execute untrusted workflow files.

Prerequisites: Python 3, Node.js supported by n8n 2.45.4, and n8n 2.45.4 installed
in a separate directory. Set the paths below for your computer. No paid API needed.

python scripts/reproduce.py --n8n-bin /absolute/runtime/node_modules/n8n/bin/n8n --user-folder /absolute/isolated-user-folder --output /absolute/results --model /absolute/kit/model.mjs

Repeat with --patch-only to execute the clone generated by insertAppend.
Use an empty user folder, separate from an existing n8n account. The script imports
four named synthetic workflows across the two runs. It does not start a daemon.
Raw CLI logs can contain internal n8n values; keep the generated private-logs private.

Observed on 2026-10-27, n8n 2.45.4, execution order v1, five synthetic items:
direct branches + batching: 2 HTTP calls; Append + batching: 1; Append alone: 5.
The tool-generated Append clone: 1 HTTP call. No external billing was measured.
Empty branches, custom code, retries, loops and item pairing require their own test.

Files:
model.mjs: original local parser, graph analysis and reviewed clone generator.
example.json: network-free example; not the HTTP-counter fixture.
benchmark.json: reduced observed receipts with fixture hashes.
tests/fanin.test.mjs: run with node --test tests/fanin.test.mjs.
scripts/reproduce.py: finite native harness described above.
